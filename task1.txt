52 ?- edge(A,A) = edge(b,c).
false.
A must have the same value in both positions, but this would require A=band A=c at the same time. Since b and c are different, unification fails.
53 ?- edge(A,A) = edge(b,b).

54 ?- A = B, B = f.

55 ?- A = B, B = f, A = e.
false.
A and B are first unified, then B = f makes both equal to f. The condition A=e conflicts with this because f and e are different.
